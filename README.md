# Flux · 수학 시험지 편집기

## 벚꽃 문제지 PDF와 GitHub Actions

편집기 상단의 **벚꽃 문제지**에서 원본 디자인의 완성 PDF(8쪽)를 내려받거나, 원본 8문항을 별도 문서로 열어 편집할 수 있습니다. 기존 문서는 보관합니다. A4 세로, 한 쪽 한 문항, 나눔고딕 15.5pt와 Euler 수식체, 원본 배경을 사용합니다. 제목·정답·해설·표지는 출력하지 않습니다.

현재 문서의 본문·조건·박스·최대 5개 선택지를 **조판 소스 ZIP**으로 내보냅니다. 이미지·보기·글머리표는 명시적으로 거부하며 내용이 조용히 누락되지 않습니다. 소스 ZIP 안의 README에 실행 방법이 있습니다.

- 로컬: `npm ci`, `python -m pip install PyMuPDF==1.26.6 pillow`, XeLaTeX 설치 후 `npm run pink:prepare`. `npm run pdf:server`와 `npm run dev`를 함께 실행하면 **현재 문서 PDF 생성**을 사용할 수 있습니다. Tectonic도 지원합니다.
- 배포판: 벚꽃 문제지 → GitHub Actions에서 PDF 만들기 → 문항 JSON 저장 → [Build worksheet PDF](https://github.com/nst333/Flux/actions/workflows/worksheet.yml)의 Run workflow → `document_json`에 JSON 전체 붙여넣기 → 실행의 `worksheet` 아티팩트 다운로드. 저장소 쓰기 권한이 필요합니다. 제출한 문항은 GitHub Actions로 전송됩니다. 입력을 비우면 원본 8문항을 생성합니다.
- 웹앱 배포: [Flux](https://nst333.github.io/Flux/). `main`에 반영하면 테스트·원본 PDF 조판·검수·Vite 빌드 후 GitHub Pages로 배포합니다. 이 정적 호스팅은 XeLaTeX 서버를 실행하지 않으므로 수정 문항의 즉시 PDF 생성은 로컬 서비스 또는 Actions에서 수행합니다.

원본 배경·글꼴·기준 PDF와 기존 앱의 바이너리 자산은 `templates/assets.zip`에 보관합니다. `scripts/prepare-pink.mjs`가 압축을 풀며 원본을 다시 그리지 않습니다. 글꼴 사용권은 `templates/pink/licenses/`에 있습니다. PC 전용 한컴 글꼴은 포함하지 않습니다.

`output/pdf/pink-verification.json`은 실제 생성물의 8쪽·A4·사용 글꼴 포함 여부·원본 픽셀 비교 결과를 기록합니다. 원본 배경에는 사용하지 않는 Helvetica 리소스 선언이 있으며, 실제 글자를 표시하는 모든 글꼴의 포함을 검사합니다. Tectonic/TeX Live 버전에 따라 픽셀 차이가 있을 수 있으므로 픽셀 일치를 주장하지 않습니다. LaTeX 제어 명령은 허용 목록으로 제한하고 셸 실행을 끕니다. 글꼴 누락이나 가로·세로 넘침이 감지되면 출력을 중단합니다.


## 다크 글라스 개편

- 기본 다크 테마와 효과 줄이기 설정은 브라우저에 저장됩니다. 유리 표면에는 빌드 때 생성한 작은 블러 이미지를 사용하며 실시간 블러를 중첩하지 않습니다.
- 프로젝트 루트의 `background.svg`를 원하는 `background.png`, `background.jpg`, `background.webp`, `background.avif` 또는 `background.svg` 하나로 교체하고 개발 서버를 다시 시작하거나 빌드하세요. 같은 이름의 이미지를 둘 이상 두면 빌드를 중단합니다. 원본은 배포하지 않습니다.
- 새 문서는 평가원 A3·본문 11.48pt·수식 10.98pt를 사용합니다. 교육청 A3·본문 11.52pt·수식 11.04pt는 시험지 설정의 출력 양식에서 선택합니다. 기존 문서는 자동으로 크기를 바꾸지 않습니다.
- 입력은 글과 LaTeX 원문을 한 칸에 쓰는 방식입니다. 입력 도구는 각 입력칸의 `…`에서 열고, 이미지의 크기·정렬은 접힌 설정에서 조절합니다. 현재 문항을 크게 표시하는 미리보기가 기본이며 전체 시험지로 전환할 수 있습니다.
- 입력이 180ms 멈추면 미리보기를 갱신합니다. 문항 목록과 수식·문항 높이는 재사용하고, 인쇄는 최신 문서의 배치가 완료된 뒤 허용합니다.
- **한글 파일**은 브라우저에서 편집 가능한 HWPX를 생성합니다. 원래 서체 이름과 수식 개체를 기록하며, 수식을 변환할 수 없으면 문항과 원문을 표시하고 내보내기를 중단합니다. 파일은 서버로 보내지 않습니다.
- 설치된 한글 2022에서 HWPX를 열고 PDF로 저장하는 검증은 성공했습니다. 그러나 **웹 단독으로 원래 HFT 서체를 처리해 공식 시험지와 동일한 PDF를 만드는 기능은 구현 완료가 아닙니다.** 브라우저 인쇄 PDF와 HWPX 내보내기를 원서체 웹 PDF로 표시하지 않습니다.
- 실제 원서체는 한컴 설치 폴더에서 확인해 `local-fonts/`에 복사했습니다. 이 폴더는 Git과 공개 빌드에서 제외합니다. 출처는 `local-fonts/sources.json`, 검색 결과는 `analysis/font-search.json`과 `analysis/hft-font-search.json`에 있습니다.
- 일반 시험지의 한컴 원서체 PDF와 벚꽃 양식의 XeLaTeX PDF는 별도 출력입니다. 현재 GitHub Actions 배포는 벚꽃 양식 조판을 포함합니다.

검증: `npm test`, `node scripts/glass-test.cjs`, `npm run test:browser`, `npm run test:edges`. 배포 빌드의 성능은 `node scripts/performance-test.cjs http://127.0.0.1:4173/`로 측정합니다. 설치된 한글을 이용한 로컬 호환성 검증용 스크립트는 `scripts/verify-hwpx.ps1`이며 앱의 실행 의존성에는 포함되지 않습니다.

최종 로컬 측정에서 CPU 6배 제한의 입력 반응 p95는 30문항 124.9ms, 100문항 221.1ms였으며, 입력 후 미리보기 갱신은 각각 580.7ms와 519.7ms였습니다. 키 입력부터 두 번의 requestAnimationFrame까지 측정한 근사치이며 표준 INP 측정은 아닙니다. 100ms 목표는 아직 충족하지 못했습니다. 상세 결과는 `analysis/performance.json`에 기록합니다.

PC의 Chrome 또는 Edge에서 사용하는 개인용 수학 시험지 편집기입니다. 서버 계정 없이 문항을 작성하고 브라우저 자동 저장과 파일 백업을 사용할 수 있습니다.

UI는 [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR)을 사용하며, 본문 400·제목 600·브랜드 700 굵기로 구분합니다. 글꼴은 외부 CDN 없이 앱에 포함되며, OFL 사용권 문서는 `public/fonts/`에 있습니다. 시험지용 한글·수식 글꼴은 별도로 유지합니다.

브랜드 아이콘은 수학 함수의 `f`와 시험지의 가로줄을 조합한 벡터입니다. 원본은 `public/icon.svg`이며, 앱 헤더·브라우저 탭·홈 화면에 적용합니다. PNG 크기별 파일은 `node scripts/icons.mjs`로 다시 생성할 수 있습니다.

## 실행

Node.js 22 이상이 필요합니다.

```powershell
npm install
npm run dev
```

[편집기 열기](http://127.0.0.1:5173/). Windows에서는 `start-editor.cmd`를 실행해도 됩니다. 개발 서버가 실행되는 동안 사용합니다.

## 기능

- 문서 보관함: 검색·최근 수정/이름 정렬·학년 필터·격자/목록 보기, 폴더, 즐겨찾기, 복제·삭제·가져오기·내보내기
- 기존 자동 저장 문서는 보관함으로 옮겨지며, 새 문서를 만들어도 이전 문서를 유지합니다.
- **시험지 설정 → 시험지 제목 방식**: 모의고사 양식으로 자동 생성하거나 원하는 제목을 직접 입력합니다. 직접 입력 제목은 표지·문제지·해설지·정답표에 적용되며, 보관함의 문서 이름과 별도로 저장됩니다.
- 문제 목록, 입력 영역, 미리보기의 3열 화면과 패널 너비 조절
- 텍스트·이미지·선택지·조건·박스·보기 블록
- 글머리표, 문장 속 `[[가]]`~`[[차]]` 빈칸, 2열 보기와 `(가)` 표기. 왼쪽의 **빈칸 추론 예제 추가**로 사진과 같은 유형을 만들 수 있습니다.
- LaTeX 원문 강조, 입력 중 수식 미리보기, 인라인 `$…$`와 독립 `$$…$$` 수식
- 선지 자동·5개 한 줄·3+2·2+3·세로 배치와 정답 지정
- 문항·블록 순서 변경, 복제, 삭제, 실행 취소·다시 실행
- 정답·해설 편집, 개인 블록 템플릿
- 고1·고2 단일과목형, 고3 공통·선택형과 확률과 통계·미적분·기하
- 단·페이지 넘김, 문항별 풀이 여백, 블록 경계 분할
- 문제지·정답표·해설지 인쇄와 PDF 저장
- 시험지 설정에서 표지와 빈 간지 또는 선택과목 안내 간지 추가
- IndexedDB 자동 저장, 이미지와 템플릿을 포함한 `.mathexam` 파일 저장·불러오기

PDF는 **인쇄 / PDF → 브라우저 인쇄창 → PDF로 저장**으로 출력합니다. 배율 100%, 머리말·꼬리말 해제를 권장합니다. 파일 저장은 Ctrl+S로도 실행할 수 있습니다. 브라우저 데이터를 지우면 자동 저장 문서도 지워지므로 `.mathexam` 파일을 백업하세요.

## 양식 기준과 현재 한계

2026년 3월 EBSi 공식 PDF를 읽어 용지 크기와 주요 구분선 위치를 참고했습니다.

- [고1 공식 수학 문제지](https://wdown.ebsi.co.kr/W61001/01exam/20260324/go1/math_main_mun_1X6166DA.pdf): 약 209.90 × 296.69 mm, 본문 약 8.2 pt
- [고2 공식 수학 문제지](https://wdown.ebsi.co.kr/W61001/01exam/20260324/go2/math_main_mun_B1MY7476_1.pdf): 약 296.69 × 419.81 mm, 본문 약 11.5 pt
- [고3 공식 수학 문제지](https://wdown.ebsi.co.kr/W61001/01exam/20260324/go3/math_main_mun_MQ748REX_1.pdf): 약 209.90 × 296.69 mm, 본문 약 8.2 pt

이전 버전의 교육청 양식은 고1·고3 A4, 고2 A3로 정규화했으며, 해당 문서는 유지됩니다. 새 문서에는 위의 A3 출력 양식을 적용합니다. 이전 양식에서 고1·고3의 본문 시작선은 첫 페이지 약 54 mm, 이후 약 42.4 mm를 기준으로 합니다. 바깥 여백 약 22 mm, 가운데 선 105 mm를 사용합니다. 정확한 기본 본문 크기는 고1·고3 **8.16pt**, 고2 **11.52pt**이며, 고3 제목 16.92pt, 영역명 25.44pt, 문항 번호 9.84pt, 기본 수식 7.80pt를 반영합니다.

이 PC의 한글 2022 설치 폴더에서 **한컴바탕(HBATANG), 한컴돋움(HDOTUM), HY헤드라인(H2HDRM), HY견명조(HYMJRE)**, Windows Fonts에서 **HYhwpEQ**를 읽습니다. 로컬 서버가 글꼴을 제공하며 공개 빌드·백업 파일에는 글꼴을 포함하지 않습니다. 별도 로컬 검증용 복사본은 local-fonts에 있습니다. 구형 TTF의 잘못된 cmap 종료 표시는 브라우저 로딩을 위해 메모리에서 보정합니다. 수식은 LaTeX로 배치하고 숫자·기본 연산자와 소문자 수학 이탤릭에 HY 수식 글꼴을 적용합니다. 큰 괄호·근호·일부 기호와 수식 배치 엔진은 KaTeX이므로 한글 수식과 완전히 동일하지 않습니다. 해당 설치 폴더가 없는 PC에서는 시스템 글꼴로 표시됩니다. 표지·선택 안내 간지는 이 편집기가 구성한 양식입니다.

폰트 조사에는 [한양정보통신의 서체 안내](https://www.hanyang.co.kr/company.php), [한컴의 번들 글꼴 사용 안내](https://www.hancom.com/support/faqCenter/faq/detail/1718), [함초롬 무료 사용 안내](https://download.hancom.com/support/faqCenter/faq/detail/2301)를 참고했습니다. 설치 글꼴을 다른 서비스나 PC에 배포할 경우에는 별도 사용 범위를 확인해야 합니다. 사용자가 수정한 글자 크기·행간·여백과 풀이 여백에 따라 문항 배치는 달라집니다.

고3 공통 문항 번호는 1부터, 선택 문항은 23부터 표시합니다. 22개를 넘는 공통 문항은 경고 대상입니다. 여러 선택과목을 하나의 문서에 동시에 관리하는 기능, 바이너리 HWP 내보내기, AI, 도형 직접 그리기, 이미지 자르기는 포함하지 않습니다. 이미지는 PNG·JPEG·WebP·GIF, 최대 8MB를 지원합니다.

## Netlify 배포

배포 주소: https://flux-math-jiwani277.netlify.app/

빌드 명령은 npm run build, 게시 폴더는 dist입니다. netlify.toml에 설정이 들어 있으며, 수동 업로드용 빌드는 output/flux-netlify.zip입니다. 재배포할 때는 dist를 다시 빌드하고 해당 Netlify 프로젝트에 업로드합니다.

배포판은 PC 전용 한컴 글꼴 파일을 포함하지 않습니다. 시스템에 설치된 대체 글꼴과 KaTeX 글꼴을 사용하므로 로컬 편집기와 인쇄 모양에 차이가 있을 수 있습니다. 자동 저장은 접속 주소별 브라우저 저장소에 남으며, 로컬 문서를 배포 주소로 옮길 때는 .mathexam 파일을 내보낸 뒤 가져오세요.
